# YASS — builds de teste

Builds de teste do **YASS** para Android (só os APKs, sem código).

## 📲 Instalar

**[⬇️ Baixar a última versão (yass.apk)](https://github.com/luhno/yass-releases/releases/latest/download/yass.apk)**

1. Abra o link acima no celular Android.
2. Se o Android pedir, permita **"Instalar apps desconhecidos"** para o navegador
   (Configurações → Apps → *seu navegador* → Instalar apps desconhecidos).
3. Abra o arquivo baixado e toque em **Instalar**.

> O Play Protect pode avisar que o app é desconhecido — é normal para builds de teste.
> Toque em *Mais detalhes → Instalar assim mesmo*.

## 🔄 Atualizações

A partir da **0.2.4**, você só precisa instalar uma vez: quando sair uma build nova,
o jogo mostra o cartão **"Atualização disponível"** no menu. É só tocar e instalar.

Se você tem uma versão anterior à 0.2.4, instale manualmente pelo link acima uma vez.
